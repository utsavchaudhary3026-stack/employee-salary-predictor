# Employee Salary & Appraisal Predictor (INR)

A Machine Learning web application predicting professional compensation bands and appraisal evaluations in Indian Rupees (₹ LPA).

## Overview
* **Domain:** HR Analytics / Workforce Compensation Modeling
* **Model:** Random Forest Regressor
* **Framework:** Streamlit, Scikit-Learn, Pandas, NumPy
* **Target Metric:** Compensation in Lakhs Per Annum (LPA)

## Key Features
* Dynamic feature sliders for experience, certifications, and appraisal ratings.
* Role-tier and educational weighting calculations.
* Monthly take-home estimate and merit-based increment insights.
